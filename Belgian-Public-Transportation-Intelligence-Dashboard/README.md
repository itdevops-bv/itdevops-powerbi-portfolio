# Belgian Public Transportation Intelligence Dashboard

Power BI dashboard focused on Belgian railway network analysis, route coverage, international connectivity and KPI reporting.

Key capabilities:

- Railway Network Analysis
- Station Coverage Reporting
- Cross-Border Railway Destinations
- Interactive Filtering
- Azure Maps Integration
- Network Intelligence Reporting

Technology stack:

- Microsoft Power BI
- Power Query
- DAX
- Azure Maps
- GTFS Open Data

## Areas of Expertise

- Business Intelligence
- Data Analytics
- Transportation Analytics
- Data Visualization
- Geographic Analysis
- KPI Reporting

## Dashboard Pages

### Executive Overview

Power BI dashboard focused on railway stations, destinations and route analysis.

Key capabilities:

- Railway Stations KPI
- Railway Routes KPI
- Interactive Filtering
- Top 10 Railway Destinations
- Executive-Level Reporting

### Network Coverage Analysis

Power BI dashboard focused on network coverage and international railway connectivity.

Key capabilities:

- NMBS International Rail Network
- Azure Maps Visualization
- Cross-Border Railway Analysis
- International Connectivity Insights
- Top Cross-Border Railway Destinations
